# מבנה חוברת ה-Excel הישנה – מדריך לכלי הייבוא

הקובץ: `data/legacy/31.08.2026_בית_הכנסת_ברית_שלום.xlsm`. קוד ה-VBA המלא: `vba_source.txt`.
כל האינדקסים להלן הם 1-based (כמו ב-Excel / openpyxl).

## גיליון `חברי בית הכנסת` (מוסתר)

| עמודה | כותרת | הערות |
|---|---|---|
| A | מספר חבר | 1..90, רץ |
| B | שם פרטי | לעיתים עם רווח מיותר בסוף |
| C | שם משפחה | לעיתים עם הערה בסוגריים: `כהן(יעקב כהן)` → nickname |
| D | מס' נייד | טקסט, לעיתים ריק |
| E | הערות | למשל `כולל האורחים`, `אורחי יצחק כהן` |

שורה 1 כותרות, נתונים משורה 2. שורה אחרונה = מספר החברים + 1.

## גיליון `כרטיסיות` (מוסתר) – הליבה

בלוק של **10 עמודות לכל חבר**. לחבר מספר `n` (1-based): עמודת הבסיס `base = (n-1)*10`.

| עמודה יחסית | מוחלטת (חבר 1) | שורה 1–5 | שורות 6–201 (תנועות) |
|---|---|---|---|
| base+1 | A | ריק | ריק (מפריד) |
| base+2 | B | B1 = מספר חבר; B2 = 'שם'; B3 = 'יתרת חוב'; B4 = 'חיוב'; B5 = 'תאריך' | **תאריך נדר** (טקסט!) |
| base+3 | C | C5 = 'פרשת שבוע' | **פרשה/אירוע** (טקסט חופשי) |
| base+4 | D | D2 = שם פרטי; D5 = 'סכום' | **סכום חיוב** (מספר; שלילי = זיכוי) |
| base+5 | E | E2 = 'משפחה'; E3 = `=D202-F202` (יתרת חוב); E4 = 'זיכוי'; E5 = 'תאריך תשלום' | **תאריך תשלום** (טקסט) |
| base+6 | F | F5 = 'סכום' | **סכום תשלום** |
| base+7 | G | G5 = 'סטאטוס' | `שולם` / `שולם והודפס` |
| base+8 | H | H2 = שם משפחה; H5 = 'סוג תשלום' | אמצעי תשלום (יש ערכים פגומים: `100`, `שולם והודפס`, `מזומן-מאיר חזן`) |
| base+9 | I | I5 = "מס' קבלה" | מספר קבלה |
| base+10 | J | J5 = 'תאריך הפקת קבלה' | תאריך אמיתי (datetime) |

שורה 202: `D202 = SUM(D6:D201)`, `F202 = SUM(F6:F201)`.
**צד החיוב וצד הזיכוי אינם מקושרים שורה-לשורה** – שורה `i` בצד חיוב ושורה `i` בצד זיכוי הן תנועות בלתי תלויות. יש לקרוא כל צד בנפרד ולעצור בתא ריק בעמודת התאריך של אותו צד.

A מס"ד, B תאריך (טקסט), C שם התורם (לעיתים כולל ייעוד: `סמי דדון - משכורת לרב חודש מאי 24`), D סוג תרומה (`בדק בית`/`ברכת השנה`), E אופן התרומה, F סך התרומה, G הערות, H מספר קבלה, I תאריך הפקת קבלה (datetime). 45 רשומות.

## גיליון `הוצאות` (מוסתר)

A מס"ד, B תאריך (טקסט; שורה 8 מכילה מספר `29.092023`!), C סך ההוצאה (שלילי = החזר; נמצא −3000), D פרוט ההוצאה, E הערות (אסמכתא – מספר חשבונית/ספק). 170 רשומות. **השורה האחרונה בעמודה C היא שורת סיכום ללא מס"ד – לדלג.**

## גיליון `מספר קבלה` (מוסתר)

עמודה A: 1..452. מונה גלובלי משותף לנדרים ולתרומות. `MAX(A)` = מספר הקבלה האחרון.

## גיליון `קבלות` (מוסתר) – תבנית הדפסה

B2 שם בית הכנסת, B3 יישוב, F5 מס' קבלה, G5 שנה עברית (טקסט קבוע `תשפ"ב` – שגוי), F7 שם המשלם, E9 אמצעי, F9 סכום, G11 תאריך תשלום, B13 `בתודה וועד בית הכנסת`, E15 תאריך הפקה, G15 חתימה. A4 לרוחב.

שורות 3–39 = 37 חודשים (09/2023 – 09/2026). A חודש (datetime), B תרומות, C נדרים (= **תשלומים בפועל**, לא חיובים), D סה"כ, E הוצאות, F יתרה, G יתרה מצטברת. שורה 40 סיכומים. משמש לבדיקת הצלבה של הייבוא.

## כללי סיווג בייבוא

- שורת חיוב שהפרשה שלה מתחילה ב-`זיכוי` **או** שהסכום שלילי → `vow_charge.kind='credit'`, `amount = ABS`.
- פרשה `יתרות תשפ"ג` / `יתרות תשפ"ג ...` → `kind='opening'`, תאריך `2023-09-01`.
- פרשה עם מקף/רווח + שם (`אמור- זגורי`, `ויגש -חיים`) → `occasion = 'אמור'`, `occasion_note = 'זגורי'`.
- שגיאות כתיב ידועות → מיפוי בקובץ `tools/import/occasion-map.json` (למשל `פחקודי`→`פקודי`, `ניצבין וילך`→`נצבים-וילך`, `מטות מעי`→`מטות-מסעי`, `בוא`→`בא`, `מיקץ`→`מקץ`, `טישב`→`וישב`?? → דגל לבדיקה ידנית).
- מה שלא ממופה → `occasion='אחר'`, `occasion_note=<המקור>`, שורה בדוח חריגים.
- אמצעי תשלום לא מזוהה → `מזומן` + שורה בדוח חריגים.
