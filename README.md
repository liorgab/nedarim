# NEDARIM

מערכת ניהול נדרים, תרומות והוצאות לבית כנסת – יישום Windows עצמאי (Offline) שמחליף חוברת Excel/VBA.

- **איפיון:** `docs/SPEC.md` (וגם `docs/איפיון_מערכת_נדרים_ותרומות.docx` להדפסה)
- **סכימה:** `docs/DATA-MODEL.md`
- **מפת דרכים:** `ROADMAP.md`
- **הנחיות ל-Claude Code:** `CLAUDE.md`
- **פרומפט פתיחה:** `KICKOFF-PROMPT.md`
- **מקור:** `data/legacy/` (הקובץ המקורי), `docs/legacy/` (מבנה החוברת + קוד VBA)

## הרצה

```bash
npm run install:clean   # ראו הערה למטה – לא `npm install` רגיל
npm run dev             # הרצה בפיתוח
npm run check           # tsc + eslint
npm test                # Vitest
```

> **למה לא `npm install` רגיל:** ל-`better-sqlite3` יש `binding.gyp` ואין לו
> `install script`, ולכן npm מריץ לו `node-gyp rebuild` אוטומטי שדורש
> Visual Studio ונכשל על מכונה נקייה. הקומפילציה מיותרת – החבילה מגיעה עם
> prebuilds של N-API שטובים גם ל-Node וגם ל-Electron. `install:clean`
> מדלג על הסקריפטים ומוריד רק את הבינארי של Electron, שהוא היחיד שנדרש.

## ייבוא מהקובץ הישן (חד-פעמי)

```bash
npm run import -- "data/legacy/<file>.xlsm"
# ייבוא ישירות ל-DB של היישום:
npm run import -- "data/legacy/<file>.xlsm" --db "%APPDATA%/nedarim/nedarim.db"
```

הייבוא אידמפוטנטי – אפשר להריץ שוב ושוב. הוא מפיק `data/import-report.md` עם דוח חריגים
ודוח התאמה מלא מול הקובץ הישן.

## דרישות

Windows 10/11 x64. אין צורך ב-Office, ב-Visual Studio Build Tools או בחיבור לאינטרנט.
`better-sqlite3` נטען מ-prebuild של Node-API ולכן אינו דורש קומפילציה.

## פרטיות

**המערכת אינה מתחברת לאינטרנט ואינה שולחת שום נתון לשום מקום.** אין
אנליטיקס, אין טלמטריה, אין ענן, אין חשבון משתמש. כל הנתונים יושבים בקובץ
SQLite אחד במחשב שלך.

החריג היחיד הוא מודול הוואטסאפ, שכבוי כברירת מחדל.

**המדיניות המלאה: [`PRIVACY.md`](PRIVACY.md)** – והיא קריאה גם מתוך
היישום עצמו, בהגדרות ← אודות ורישוי.

## מצב הפיתוח

| שלב | מצב |
|---|---|
| 1–4 – ליבה, נדרים, תשלומים, קבלות, דוחות, גיבוי, אבטחה | הושלם |
| 7 – לוח שנה עברי-לועזי | הושלם |
| 6 – וואטסאפ (W0–W2) | הקוד הושלם; **שליחה אמיתית ממתינה לבדיקת שטח** |
| 6 – וואטסאפ (W3–W5) | טרם נבנה – קמפיינים, היסטוריה, הקשחה |

`ROADMAP.md` מחזיק את התמונה המלאה. מה שמסומן `[~]` פירושו שהקוד קיים אבל טרם
אומת מול שימוש אמיתי – אל תסתמכו עליו בייצור.
