# NEDARIM – נדרים

מערכת ניהול נדרים, תרומות והוצאות לבית כנסת. יישום Windows עצמאי שרץ **ללא
אינטרנט**, בעברית מלאה (RTL), ומחליף חוברת Excel/VBA.

התקנה אחת = בית כנסת אחד. אין ענן, אין חשבון משתמש, אין דמי מנוי. כל הנתונים
יושבים בקובץ SQLite אחד במחשב של הגבאי.

---

## מה המערכת עושה

### נדרים, תשלומים ויתרות

- **חברים** עם כרטיסייה אישית: כל הנדרים, התשלומים, הקבלות והיתרה במקום אחד.
- **הזנת נדר** עם תאריך עברי, פרשת השבוע והחג – מחושבים אוטומטית מהתאריך
  הלועזי. יש גם **הזנה מרובה** למוצאי שבת: שורה לכל חבר, תאריך ופרשה
  משותפים, שמירה אחת.
- **תשלומים** מלאים או חלקיים, זיכויים (מחיקת חוב, הנחה, חיוב בטעות) עם סיבה
  ורישום ביומן.
- **יתרות מחושבות בזמן אמת** מתוך החיובים והתשלומים – לא נשמרות ולכן לא
  יכולות "להתקלקל".

### קבלות – בלי להדפיס

- הקבלה מופקת כ**קובץ PDF** ונשמרת בארכיון על המחשב. **הדפסה היא אפשרות,
  לא חובה**: אפשר להסתכל בתצוגה מקדימה, לשמור, ולשלוח או להדפיס אחר כך.
- **מספר קבלה עוקב**, שמוקצה בטרנזקציה ולעולם אינו משוחרר או נערך. ספר
  הקבלות כולל בדיקת רציפות שמתריעה אם חסר מספר.
- הקבלה **אינה ניתנת לעריכה** – תיקון נעשה בביטול והפקה מחדש, עם סיבה
  ורישום ביומן הביקורת.
- הסכום מופיע גם במילים, עם התאריך העברי והלועזי, לוגו בית הכנסת וחתימה.

### תרומות והוצאות

- יומן תרומות עם סוגי תרומה, תורם שאינו חבר, ואסמכתאות.
- יומן הוצאות עם קטגוריות, ספקים, **צירוף קובץ סרוק** לכל הוצאה, והחזרים.

### מאזן ודוחות

- מאזן חודשי ושנתי – הכנסות, הוצאות ויתרה מצטברת. הטווח נבחר לפי שנה כספית,
  שנה עברית, שנה אזרחית או טווח חופשי.
- דוחות: יתרות חוב לפי גובה וגיל החוב, נדרים לפי פרשה ואירוע, תרומות, הוצאות,
  תקבולים לפי אמצעי תשלום, ודף חשבון לחבר. בנוסף – ספר קבלות עם בדיקת רציפות.
- **כל טבלה** במערכת ניתנת למיון, לסינון, ולייצוא – והסיכומים משתנים לפי
  הסינון הפעיל.

### שליחת הודעות בוואטסאפ

- **הודעה בכל אירוע כספי** – נדר, תשלום, קבלה, תרומה – כך שההתכתבות עם החבר
  הופכת ליומן של כל ההתחשבנות מול בית הכנסת.
- **שליחה מרוכזת** לרשימת חברים או לכל החייבים, מתוך תבניות הודעה שאפשר
  לערוך (`{שם}`, `{יתרה}`, `{תאריך}` ועוד), עם תצוגה מקדימה של ההודעה שתישלח
  לכל אחד.
- מנוע השליחה נבנה **כדי לא להיחסם**: השהיה אקראית בין הודעות, מכסה יומית
  שנשמרת גם אחרי הפעלה מחדש, ועצירה אוטומטית אחרי כמה כשלים רצופים או כשהחיבור
  נותק. מודאל ההתקדמות מציג מה נשלח, מה נכשל ולמה, עם השהיה/המשך/ביטול.
- **המודול כבוי כברירת מחדל.** הוא עובד דרך WhatsApp Web בחלון של היישום,
  עם המספר שלכם, אחרי סריקת QR. אין שירות חיצוני ואין מספר של מישהו אחר.

### גיבוי ושחזור

- **גיבוי בלחיצה** – עותק של בסיס הנתונים, של ארכיון הקבלות ושל הקבצים
  המצורפים, עם מניפסט ו-checksum.
- **שחזור** מציג מה יש בגיבוי (כמה חברים, כמה קבלות, סך היתרות) **לפני**
  שמחליפים, ויוצר גיבוי בטיחות של המצב הנוכחי. גיבוי פגום אינו ניתן לשחזור
  בכלל.
- **תזכורת** לגיבוי חיצוני (דיסק און קי / תיקייה מסונכרנת) אם עברו יותר מדי
  ימים.
- הפורמט פתוח: אפשר לשחזר גם בלי המערכת, פשוט להעתיק את `nedarim.db` חזרה.

### ייבוא וייצוא מקובצי אקסל

- **ייצוא מלא** של כל הנתונים לקובץ Excel אחד, גיליון לכל ישות – כדי שבית
  הכנסת לעולם לא יהיה נעול במערכת. כל דוח וכל טבלה מתייצאים גם ל-CSV
  ול-Excel ומודפסים.
- **אשף ייבוא** בן שישה שלבים (שיטת ייבוא · העלאת קובץ · מיפוי שדות · בדיקת
  תקינות · ייבוא · סיכום):
  - **תבנית אקסל להורדה**, גיליון לכל ישות, שדות חובה באדום ורשות בירוק.
  - ייבוא מהתבנית המלאה **או** מקובץ CSV בודד לישות אחת.
  - **מיפוי חכם** לקובץ שנוהל ביד: המערכת מציעה התאמה לכל שדה, מסמנת מה ודאי
    ומה ניחוש שדורש אישור, ומראה אילו עמודות לא ייובאו.
  - **ארבע שיטות**: מחיקה וייבוא מחדש, עדכון קיימות + הוספת חסרות, הוספת
    חסרות בלבד, והעשרה (מילוי שדות ריקים בלי לדרוס ערך קיים).
  - **דיווח תקלות ברור**: "תרומה לחבר 47 – החבר אינו קיים", עם הגיליון, העמודה
    ומספר השורה. שגיאות חוזרות מקובצות לשורה אחת עם דוגמאות.
  - **תצוגה מקדימה** לפני הכתיבה, והכול נכתב בפעולה אחת: כישלון מחזיר את המצב
    בדיוק לקדמותו.

### לוח שנה עברי

טווח תאריכים, ולכל יום: תאריך לועזי, תאריך עברי, יום בשבוע, פרשת השבוע, חג,
והאירוע שיוצע בהזנת נדר. עם ייצוא והדפסה.

### ניהול, אבטחה ועדכונים

- **אשף התקנה ראשונה**: שם בית הכנסת, מספר הקבלה הראשון, שנה כספית וגיבוי –
  הכול מוגדר לפני שמתחילים לעבוד. אין ערכים של בית כנסת אחר בקוד.
- **מספר משתמשים והרשאות** (מנהל / פקיד / צפייה בלבד), נעילה אוטומטית לאחר חוסר
  פעילות, ו**יומן ביקורת** לכל שינוי בנתון כספי – מה היה לפני ומה אחרי.
- **מחיקת כל הנתונים מהמחשב** בהגדרות, עם גיבוי מלא שנוצר אוטומטית לפני
  המחיקה והקלדת שם בית הכנסת לאישור.
- **בדיקת עדכון בלחיצה**: כפתור שבודק אם יצאה גרסה חדשה ב-GitHub. אין בדיקה
  אוטומטית ואין שליחת מידע – הבדיקה קורית רק כשלוחצים.

## התקנה

1. גשו ל-[**Releases**](https://github.com/liorgab/nedarim/releases).
2. הורידו את `nedarim-setup-<גרסה>.exe` מהגרסה האחרונה.
3. הריצו את קובץ ההתקנה. Windows עשוי להציג אזהרת SmartScreen – ההתקנה אינה
   חתומה דיגיטלית (חתימה עולה כסף ואינה משנה דבר לגבי מה שהקוד עושה; הקוד
   כולו כאן, ואפשר לבנות אותו בעצמכם).
4. בהפעלה הראשונה ייפתח אשף ההתקנה, ואחריו אשף הייבוא.

**דרישות:** Windows 10/11 x64. אין צורך ב-Office, ב-Visual Studio או בחיבור
לאינטרנט.

**עדכון:** הגדרות ← אודות ורישוי ← "בדוק אם יש עדכון". הגרסה הנוכחית מוצגת
שם, יחד עם מה שהשתנה ([`CHANGELOG.md`](CHANGELOG.md)).

בהגדרות ← אודות ורישוי.

## פיתוח

```bash
npm run install:clean   # ראו הערה למטה – לא `npm install` רגיל
npm run dev             # הרצה בפיתוח
npm run check           # tsc + eslint
npm test                # Vitest
npm run build           # קובץ התקנה
```

> **למה לא `npm install` רגיל:** ל-`better-sqlite3` יש `binding.gyp` ואין לו
> `install script`, ולכן npm מריץ לו `node-gyp rebuild` אוטומטי שדורש
> Visual Studio ונכשל על מכונה נקייה. הקומפילציה מיותרת – החבילה מגיעה עם
> prebuilds של N-API שטובים גם ל-Node וגם ל-Electron. `install:clean`
> מדלג על הסקריפטים ומוריד רק את הבינארי של Electron, שהוא היחיד שנדרש.

**מסמכים:** `docs/SPEC.md` (איפיון מלא), `docs/DATA-MODEL.md` (סכימה),
`ROADMAP.md` (מפת דרכים), `CLAUDE.md` (הנחיות עבודה), `CONTRIBUTING.md`.

### ייבוא מהקובץ הישן (כלי שורת פקודה)

המסלול הרגיל הוא אשף הייבוא שבתוך היישום. הכלי הזה נועד להסבה חד-פעמית
מחוברת ה-Excel המקורית, עם דוח התאמה מלא:

```bash
npm run import -- "data/legacy/<file>.xlsm"
npm run import -- "data/legacy/<file>.xlsm" --db "%APPDATA%/nedarim/nedarim.db"
```

הייבוא אידמפוטנטי – אפשר להריץ שוב ושוב. הוא מפיק `data/import-report.md` עם
דוח חריגים ודוח התאמה מול הקובץ הישן.
